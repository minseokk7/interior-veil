# Interior Veil (결계 시스템)

Fabric 1.21.10용 신호기 기반 원형 은신 결계 및 전술 궤도 폭격 모드입니다. 결계 내부는 별도의 포켓 차원에 존재하며, 열쇠가 없는 외부 플레이어는 짙은 안개와 결계 방어막에 둘러싸여 내부를 볼 수 없습니다.

## ✨ 주요 기능

1. **포켓 차원 은신 결계 (Pocket Dimension Veil)**:
   - 신호기를 결계 열쇠로 활성화하면 신호기와 내부 구조물이 독립된 포켓 차원으로 안전하게 이동합니다.
   - 열쇠를 인벤토리에 소지한 플레이어는 맑은 시야로 출입할 수 있으며, 외부 침입자는 결계 안개에 가려 내부를 볼 수 없습니다.
2. **실사 3D 시네마틱 전술 궤도 폭격 (Orbital Strike & Thermal Storm)**:
   - 궤도 레이저 기둥, 3단계 광역 열폭풍(Thermal Storm Shockwave), 3D 실사 핵폭발 버섯구름(Nuclear Canopy Dome)을 3차원 볼륨으로 렌더링합니다.
   - 결계 내부는 100% 방호되며, 바깥 영역은 편향 스트림(Shield Wash Effect)으로 시각적 웅장함을 제공합니다.
3. **Xaero's World Map 완벽 연동**:
   - Xaero 세계 지도 화면 위에 결계 영역 반투명 원 및 네온 링 테두리, 조준선 오버레이 실시간 렌더링.
   - 마우스 좌클릭으로 목표 지점을 찍고 **`V` 키**를 누르면 해당 지점으로 궤도 폭격이 고정 발사됩니다. (줌 인/아웃 시 1:1 완벽 정밀 투영)
4. **Sodium(소듐) & Iris 셰이더 완벽 호환**:
   - Sodium의 커스텀 청크 렌더러와 완벽 호환되는 지형 안개(FogData 주입) 시스템 적용.
5. **마인크래프트 설정 ➔ 키 지정 메뉴 지원**:
   - `결계 시스템 (Interior Veil)` 전용 카테고리로 궤도 폭격(`V`), 설정창(`O`), 전술 맵(`J`) 단축키를 자유롭게 변경 가능.
